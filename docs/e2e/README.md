## 보류 사유

| 모듈          | 보류 사유                                                                                    | 해제 조건                                             |
| ------------- | -------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| 일정          | Cloud Tasks가 GCP 인증을 시도하여 테스트 환경에서 500 발생                                   | QueueService를 포트/어댑터 패턴으로 전환 후 Mock 주입 |
| 알림          | 알림 생성이 도메인 이벤트 핸들러에서 자동 트리거되어 단독 테스트 어려움 + FCM 발송 Mock 필요 | 포트/어댑터 전환 후 Mock 주입                         |
| 위치 추적     | IN_PROGRESS 상태 일정이 필요하나 Cloud Tasks 없이 상태 전환 불가                             | 일정 보류 해제 후 진행                                |
| 디바이스 토큰 | FCM dry-run 검증이 실제 Firebase 연결을 시도                                                 | Firebase 서비스를 포트/어댑터로 전환 후 Mock 주입     |
| 앱 버전       | ~~기술적 차단 없으나 P3 우선순위로 후순위 배치~~ → 스펙 작성 완료                            | 테스트 코드 작성 대기                                 |

> 보류된 모듈은 **Phase B(코드 일관성 리팩토링)** 에서 포트/어댑터 패턴 전환이 완료되면 순차적으로 해제됩니다.
